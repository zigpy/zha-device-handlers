# SmartPad TS0601 diagnostic provenance

The adjacent JSON is a minimal device-only extract of a real Home Assistant
device diagnostic exported on 2026-11-14. Hardware: SmartPad Zigbee Tactile Light
Switch, two gangs, neutral powered; manufacturer `_TZE28C1000000_zpvusbtv`,
model `TS0601`, reported firmware `0x00000063`.

The IEEE and NWK addresses are **synthetic fixture identifiers**, explicitly
marked in `_sanitization`. They are not measurements of the physical device.
The original signature, node descriptor, timestamp and retained attribute values
are observed values. No hardware descriptor or datapoint measurement was invented.
Host configuration, device/room names, entity names, integration inventory,
neighbors, routes and unrelated attribute data were omitted. The unmodified
household diagnostic and debug log are intentionally not published.

## Observed functions

| DP | Tuya type | Function | Evidence and limits |
|---|---|---|---|
| 1 / 2 | bool `0x01` | Channel 1 / Channel 2 | Independent physical keys and relay commands tested in both directions |
| 102 | value `0x02`, 4 bytes | LED brightness | Physical brightness changes confirmed; reports include 16, 17, 20, 30, 48, 69, 100; zero and brightness persistence after power loss untested |
| 103 / 104 | enum `0x04` | LED color when relay on / off | Independent color changes tested without changing loads; red/blue/green/white observed |
| 15 | enum `0x04` | LED mode | Function confirmed, raw read-only numeric diagnostic; option meanings and writes not established |
| 16 | bool `0x01` | LED enable | Physical LED on/off operation confirmed |

Color values 4-8 (yellow, magenta, cyan, warm white, warm yellow) are candidate
labels from the related `_TZE284_zpvusbtv` OEM discussed in
[zigbee2mqtt issue 29607](https://github.com/Koenkk/zigbee2mqtt/issues/29607).
They were not physically checked, and that different manufacturer is not matched
by this quirk. ON/OFF refers to the associated relay state; it is not a separate
RGB light endpoint. Brightness and the two color settings are device-wide.

Relay and color operation recovered after Home Assistant restarts and a circuit
power cycle starting with both relays off. No Tuya enchantment, startup setting
write or forced manufacturer bind was needed. The refresh button sends only
`query_data` (`0x03`), not a datapoint write. Child lock, timers and relay
power-on policies are deliberately not exposed.
